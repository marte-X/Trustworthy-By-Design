## About the book

This textbook teaches systems design engineering through a single running example: a small delivery robot. The robot is taken from vague stakeholder wishes to a verified, reviewed design. Along the way the book asks one question, over and over: *how do you build a system that is dependable, and that knows how far it can be trusted?*

Every chapter applies its methods to the same platform and records the results in a shared design **ledger**: requirements, decisions, assumptions and evidence. By the end, the reader has built and defended a complete design record rather than a set of disconnected exercises.

The book is written for final-year undergraduate and first-year graduate students in mechatronics, electrical, mechanical and robotics engineering, and for practising engineers who need the same tools.

**Features**

- 14 chapters, 98 exercises with answers and check values, and numbered worked examples
- MATLAB listings throughout, each run to confirm the results quoted in the text
- One running platform and a design ledger that ties all the chapters together
- Blank templates for every entry of the design record
- Annotated further reading, a full reference list and an index

## Prerequisites

A first course in linear algebra, probability and dynamic systems. The MATLAB listings need R2017b or later and use only base MATLAB. Most also run in GNU Octave (see the Preface for the exceptions).
